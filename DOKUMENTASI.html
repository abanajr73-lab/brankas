Brangkas PA Asril

DOKUMENTASI SISTEM INFORMASI TERENKRIPSI

1. Gambaran aplikasi

Aplikasi mempunyai landing page publik dan ruang admin. Admin tidak memakai password biasa: akses dibuka oleh private key. Setelah key tervalidasi, konten dalam dashboard didekripsi dan ditampilkan.

2. Alur kerja

Landing page ke Admin ke input private key ke PBKDF2 menghasilkan kunci AES ke dashboard; tambah konten ke AES-256-GCM encrypt ke database; sesi valid ke decrypt konten ke dashboard.

3. Implementasi keamanan

KomponenImplementasi
AksesPrivate key, bukan password biasa
Key derivationPBKDF2-SHA256, 210.000 iterasi, salt acak
EnkripsiAES-256-GCM, IV acak, authentication tag
DatabaseMenyimpan ciphertext, IV dan tag, bukan plaintext
Proteksi inputCSRF token dan PDO prepared statement

4. Struktur source

index.php: landing page; admin.php: akses key, dashboard, enkripsi/dekripsi; install.php: inisialisasi dan data contoh; config.php: koneksi dan kriptografi; database/brangkas_asril.sql: impor phpMyAdmin

5. Hasil dan pengujian

Setelah impor SQL dan inisialisasi, admin dapat melihat konten dengan private key yang benar. Konten yang dibuat dari dashboard dienkripsi sebelum tersimpan. Periksa tabel vault_contents untuk membuktikan kolom ciphertext tidak berisi plaintext.
